# Getting started

## Quick steps

1. Launch Ongenet — it opens on a **demo song** so you can press **Space** to hear the engine immediately.
2. Use **File → New / Open / Save** for standard project workflow (`.ongen` format).
3. Open the **Library** sidebar on the right for demo projects, instruments, effects, and samples.
4. Click **Settings** in the title bar to pick audio/MIDI devices, theme, control surface, and shortcuts.

## Details

### Projects

- **New** — title bar **New ▾** or **File → New**; choose a template or empty project.
- **Open / Save** — **File → Open** / **File → Save**; projects are single `.ongen` files with embedded samples.
- **Autosave** — backups land in your app data folder; recovery is offered on launch when a newer backup exists.

### Library sidebar

The right-hand **Library** starts collapsed to a tab strip. Expand it to browse:

- **Projects** — built-in demo songs and templates
- **Samples**, **Soundfonts**, **Instruments**, **Effects**, **Presets**, **FX chains**

Drag items from the library onto tracks or effect slots.

### Settings

**Settings** (title bar) covers:

- Audio/MIDI device selection
- Theme (four Catppuccin flavours + custom JSON)
- Control surface and keyboard shortcuts
- Library folders (samples, soundfonts)
