# Field modular

## Quick steps

1. Add a **Field** instrument or effect from the built-in list, or open the Field editor from an instrument slot.
2. Right-click the canvas → add nodes from the **module library** (oscillators, filters, envelopes, math).
3. Drag from **output ports** to **input ports** to patch audio, CV, and note signals.
4. Use **Scale Quantize** / **Key Root** nodes for theory-aware patches.

## Details

Field is Ongenet's node-graph instrument and effect (modular grid patching):

- **Colour-coded wires** — audio, CV, and note signals
- **Navigation** — middle-drag to pan, scroll to zoom
- **CV modulation** — every knob gains a CV inlet; patch LFOs, envelopes, or macros into any parameter
- **Factory patches** — ship in the preset library as editable graphs, not black boxes
- **Module nodes** — wrap any built-in or hosted plugin as a patchable block inside Field

Open the Field editor from a track's instrument slot or by adding Field from **Library → Instruments**.
