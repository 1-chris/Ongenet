# Keyboard shortcuts

## Global (when not typing in a text field)

| Shortcut | Action |
| --- | --- |
| **Ctrl+N** | New project |
| **Ctrl+O** | Open |
| **Ctrl+S** | Save |
| **Ctrl+Shift+S** | Save As |
| **Ctrl+Z** | Undo |
| **Ctrl+Y** / **Ctrl+Shift+Z** | Redo |
| **Space** | Play / stop |
| **Ctrl+Alt+T** | Tempo map |
| **Ctrl+Alt+L** | Section playlist |
| **Ctrl+Shift+I** | Ripple insert bar |
| **Ctrl+Shift+Backspace** | Ripple delete bar |
| **Shift+[** / **Shift+]** | Set loop in/out to start marker |
| **F8** | Renderer diagnostics |

## Timeline (focus timeline first)

| Shortcut | Action |
| --- | --- |
| **Delete** | Remove clip |
| **Ctrl+D** | Duplicate clip |

## Piano roll (focus piano roll)

| Shortcut | Action |
| --- | --- |
| **Delete** | Remove selected notes |

## Typing keyboard

**Z-row** and **Q-row** play notes on instrument tracks (FL-style map).

## Customize

**Settings → MIDI → Keyboard shortcuts** — remap ripple, tempo, playlist, and other bindings.

For the complete list including per-view shortcuts, see [Dev: Main window layout](/dev/main-window-layout.html).
