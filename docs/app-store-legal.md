## Google Play — Data safety

Answer **No** / **Not collected** for all user data categories. Ongenet does not collect, store, or transmit personal or usage data to the developer.

| Question | Answer |
|----------|--------|
| Does your app collect or share any of the required user data types? | **No** — mark all categories as **Not collected** |
| Is all of the user data collected by your app encrypted in transit? | **N/A** — the app does not transmit user data to the developer |
| Do you provide a way for users to request that their data is deleted? | **N/A** — no data is collected by the developer |
| Privacy Policy URL | `https://onge.net/legal/privacy.html` |

### Optional notes for the Data safety form

- Data is stored **locally on the device** only (projects, settings, presets).
- No accounts, analytics, telemetry, or crash reporting.
- Third-party audio plugins are loaded locally; their data practices are not controlled by Ongenet.
- Optional Ableton Link and OSC features use the **local network only** when enabled by the user.
